# DemoChart

Solana memecoin paper-trading site: 100 demo SOL, a simulated pump.fun-style launchpad, badges, and funded-account challenges.

The whole site is one file: `index.html`. There is nothing to build or install.

## Deploy on Vercel
1. Import this repo on vercel.com (Add New → Project).
2. Leave every setting on its default (Framework Preset: Other) and click Deploy.

## Deploy on GitHub Pages
Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: main, folder: / (root) → Save.
